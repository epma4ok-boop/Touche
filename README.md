# Touché — обновление «Дневника желаний»

Архив содержит файлы для замены в исходном проекте Touché. Распакуйте его в корневую папку проекта, сохранив структуру каталогов.

## Файлы

- `src/components/WishMap.tsx` — экран, обложка, переводы, форма желания и короткий статус отправки.
- `src/pages/Home.tsx` — подключение «Дневника желаний» на главном экране.
- `src/utils/wishShareImage.ts` — генерация изображения Wish Card с новой иллюстрацией.
- `api/couple/intimacy.ts` — обработка Wish Card и отправка изображения партнёру.
- `migration_wish_map.sql` — схема таблиц, индексы, RLS и серверная функция для отметок общих заданий.
- `public/images/wish-diary-cover.png` — иллюстрация обложки и Wish Card.

## Применение

1. Скопируйте файлы в соответствующие пути проекта, заменив существующие.
2. Проверьте файл миграции и примените `migration_wish_map.sql` через текущий процесс миграций Supabase. В приложении миграция автоматически не запускается.
3. Соберите и опубликуйте фронтенд и API обычным способом для этого проекта.

В коде не хранится содержимое секретов. Используйте уже настроенные переменные окружения Supabase, Telegram и URL приложения.

Архив сам по себе не меняет внешнее Telegram-приложение и не подтверждает доставку в Telegram. Изменения вступят в силу после замены файлов, применения миграции и публикации проекта.
