# Touché — файлы ручной замены

Это комплект файлов для ручной замены в исходниках Touché. Живое Telegram-приложение этим комплектом не обновлялось.

Распакуйте архив поверх корня проекта Touché, сохранив структуру папок. Перед заменой сохраните копию своих текущих файлов.

## Что изменено

- Экран задания получил более спокойную карточку с читаемым текстом и компактными кнопками. Метка `AI PROMPT` и декоративная линейка убраны.
- Генератор получил правила разнообразия для всех пяти категорий и пяти языков. Для лёгких категорий добавлены разные форматы похвалы и нежных действий; для «Желания» — личные фото и короткие видео; для «Страсти» и «Харда» — оральные ласки, игрушки, новые позы, анальная стимуляция и другие конкретные действия.
- Повтор недавнего типа задания отсекается до показа результата, если доступны другие варианты. Проверки качества учитывают анальные действия и новые типы медиа.
- Кубики стали объёмнее, их грани и тени уточнены. Убраны подписи 18+, `02 / 03`, «мужская кость» и «женская кость». Все исходные рисунки кубиков сохранены и подготовлены в большем разрешении для чётких экранов.
- В комплект включены также файлы главного экрана и игры «Стрип или действие» из предыдущего набора, чтобы применять всё одним архивом.
