# Touché — Таро для двоих

## Установка

Это набор добавляемых и заменяемых файлов для присланной версии Touché, не отдельный проект.

1. Сохраните резервную копию текущего проекта.
2. Распакуйте архив **в корень проекта**, рядом с `package.json`, сохранив пути `src/...` и `public/...`.
3. Разрешите замену только двух существующих файлов:
   - `src/pages/GamesScreen.tsx`
   - `src/pages/GamesScreen.css`
4. Остальные файлы новые: экран Таро, его стили, каталог и логика колоды, 37 иллюстраций.
5. Выполните обычные для проекта проверку типов и сборку (`npm run typecheck`, `npm run build`), затем выложите обновление привычным способом.

Новые зависимости, переменные окружения, изменения базы данных и настройки Telegram-бота не нужны.
Само получение архива не обновляет опубликованное приложение.

## Что добавлено

- «Игры → Таро для двоих».
- Пилот доступен бесплатно, без проверки Premium и без списания лимитов других разделов.
- Одна пара читает расклад на одном телефоне.
- 23 логические карты, 37 вариантов иллюстраций.
- Сохраняются авторские названия карт и все 69 русских описаний.
- В одном раскладе выбираются три разные логические карты; альтернативные изображения одной карты не могут выпасть как две разные карты.
- При нескольких иллюстрациях вариант выбирается случайно один раз и не меняется при возврате или перерисовке экрана.
- Первая карта открывает только «Что видите», вторая — только «Что чувствуете», третья — только «Что хотите».
- Открытие обычным нажатием. После каждой карты есть напоминание о разговоре и отдельное подтверждение перехода.
- Название карты находится вне иллюстрации. Иллюстрация показывается целиком, без обрезания рамки.
- После третьей карты — общий авторский вопрос, затем итог и возможность нового расклада.

## Сохранение и приватность

Выбранные карты и текущий шаг хранятся в `sessionStorage` на устройстве. В рамках того же сеанса браузера можно вернуться в «Игры», перезагрузить страницу и продолжить расклад. После полного завершения браузерного сеанса или закрытия Telegram сохранение не гарантируется.

Ответы партнёров не собираются и не отправляются на сервер. Для сброса незавершённого расклада предусмотрено подтверждение.

## Языки

Элементы интерфейса поддерживают существующие пять языков Touché. Авторские названия и толкования оставлены на русском без самовольного перевода. В других языках интерфейса показано предупреждение, что тексты карт пока на русском. Бесплатный доступ — решение для тестирования, не окончательная модель монетизации.

## Иллюстрации

Файлы находятся в `public/images/tarot/`. Их исходные названия, регистр букв и расширения `.JPG` / `.jpg` сохранены. Не переименовывайте их: на Linux/Vercel регистр важен. В архив включены уже оформленные карты с согласованной рамкой Touché.

На старте загружается только код, а иллюстрация — при открытии конкретной карты. Все 37 изображений не предзагружаются.

## Проверки

- Проверка типов присланного проекта.
- Production-сборка Vite.
- Проверка наличия 23 карт, 37 файлов, всех 69 исходных текстов и уникальности карт на 5000 раскладах.
- Пользовательский путь проверен в браузере на локальной копии: открытие трёх позиций, соответствие описаний, разные карты, стабильные ракурсы, выход/возврат, перезагрузка и продолжение, отмена сброса, итог. Проверены размеры 402 × 874 и 360 × 640.
- Реальное опубликованное Telegram-приложение не изменялось и не проверялось. Принудительный сетевой сбой при загрузке изображения в браузерном проходе не воспроизводился.
